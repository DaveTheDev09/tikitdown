How to download TikTok videos on Windows

  1. Open TikTok in your browser and find the video you want.
  2. Click the Share button under the video, then click Copy link.
  3. Open TikItDown in a new tab and paste the link into the input field.
  4. Click Download and pick the quality you want.
  5. The video saves to your Downloads folder. Play it with any media player on your PC.

The whole process takes about 10 seconds. Works on Windows 7, 8, 10, and 11.

Browser-specific instructions for Windows

Chrome

  • The most reliable browser for TikItDown on Windows. Downloads appear in a bar at the bottom of the window.
  • Files save to C:\Users\[YourName]\Downloads by default. Change this in Settings > Downloads > Location.
  • If Chrome shows a "potentially dangerous download" warning, click Keep. This is a generic warning for all .mp4 files and does not mean the file is unsafe.

Microsoft Edge

  • Edge is built into Windows 10 and 11 and works with TikItDown without any setup.
  • Downloads appear in the top-right corner. Click the download icon to see your file.
  • Edge saves to the same Downloads folder as Chrome by default.

Firefox

  • Firefox shows a download arrow in the toolbar when a file starts downloading.
  • Click the arrow to see download progress and access saved files.
  • Change the save location in Settings > General > Files and Applications > Save files to.

Where downloads save on Windows

Every major browser defaults to the Downloads folder on Windows. To find it:

  • Press Win + E to open File Explorer, then click Downloads in the left sidebar.
  • Or press Win + R, type shell:downloads and press Enter.
  • In Chrome, press Ctrl + J to open the downloads page and click Show in folder next to any file.

Playing downloaded TikTok videos on Windows

TikTok videos download as standard .mp4 files. Windows 10 and 11 include the Movies & TV app which plays them automatically. If you prefer a different player:

  • VLC Media Player - free, plays every format, no codec issues. Recommended if you download a lot of video content.
  • Windows Media Player - built into every version of Windows, plays .mp4 files without problems.
  • Media Player Classic - lightweight alternative that uses minimal system resources.

All of these play TikTok .mp4 files without conversion or additional codecs.
