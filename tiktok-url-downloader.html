Supported TikTok URL formats

TikTok uses several URL formats depending on the platform and how the link was generated. TikItDown handles all of them:

  • Full desktop URL - tiktok.com/@username/video/7123456789012345678. The complete URL you see in a browser address bar.
  • Mobile URL - m.tiktok.com/v/7123456789012345678.html. The mobile version of the same video link.
  • Short link - vm.tiktok.com/ZSeUxYabc. A condensed URL generated when you tap Share and Copy link on mobile.
  • Share links with parameters - URLs with tracking parameters, timestamps, or share codes appended. TikItDown extracts the video ID and ignores extra parameters.

The URL format doesn't matter. Whether you copied a long URL from your browser, a short link from TikTok's share menu, or a link someone sent you in a text message, paste it and TikItDown handles the rest.

Where TikTok URLs come from

TikTok generates different URLs depending on how you access the video. On desktop, the full URL appears in the address bar. On mobile, the app creates short links when you use the share button. When someone sends you a TikTok link via text, WhatsApp, or email, it's usually a short link. All of these point to the same video - TikItDown resolves them all to find the source file.

How to copy a TikTok URL

From the TikTok app

  1. Open the video.
  2. Tap Share, then tap Copy link.
  3. A short URL (vm.tiktok.com) is copied to your clipboard.

From a browser

  1. Navigate to the video on tiktok.com.
  2. Copy the URL from the address bar.
  3. This gives you the full desktop URL.

Frequently asked questions

What types of TikTok URLs does TikItDown support?+
TikItDown supports all standard TikTok URL formats including full desktop URLs, mobile URLs, short links (vm.tiktok.com), and shared links. As long as the URL points to a public TikTok video, TikItDown can download it.
What is the difference between a short link and a full URL?+
A full TikTok URL looks like tiktok.com/@username/video/1234567890. A short link is a condensed version like vm.tiktok.com/abc123 that redirects to the full URL. Both work with TikItDown.
Can I paste a TikTok URL from my browser history?+
Yes. Any valid TikTok video URL works regardless of where you copied it from - browser history, bookmarks, shared messages, or social media posts.
Do URL parameters affect the download?+
No. Extra parameters in the URL like tracking codes, timestamp markers, or share parameters do not affect the download. TikItDown identifies the video ID from the URL and ignores extra parameters.
What if the URL redirects to a different page?+
TikItDown follows redirects automatically. If a short link redirects to a full URL, TikItDown resolves it and finds the target video. If the video has been deleted or made private, you will see an error message.
